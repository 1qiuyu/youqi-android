# 云朵 · 像素猫素材包

按 `云朵-像素猫绘制需求.md` 生成的完整 33 张素材。

## 目录结构

```text
yunduo-cat-art/
  yunduo-cat/                ← 交付用扁平目录（33 张，直接拖进 Android res/drawable）
    icon-cloud-cat.png          512×512   桌面图标
    left-idle-01..04.png        64×64     左扒边 睁眼摆尾
    left-half.png               64×64     左扒边 半眯眼
    left-closed.png             64×64     左扒边 闭眼
    right-*.png                 64×64     右扒边（左组水平镜像）
    bottom-*.png                64×64     下扒边
    drag-cloud-01..04.png       64×64     拖动趴云
    chat-cloud-idle-01..04.png  64×64     站云摆尾
    chat-cloud-half/closed.png  64×64     站云半眯 / 闭眼
    jump-01..04.png             64×64     起跳过渡
  yunduo-cat-sprites.zip    ← 上面 33 张的压缩包
  png64/                    33 张 64×64 原图
  png512/                   icon 的 512×512
  src32/                    32×32 逻辑像素源图（放大前的真实尺寸）
  preview-all.png           33 张编号总览
  tools/build_sprites.py    生成脚本，改参数可重新导出
```

## 规格

- 全部 PNG，RGBA，真实透明背景，未绘制棋盘格。
- 32×32 逻辑像素绘制，NEAREST 整数倍放大：动画 2×（64×64），图标 16×（512×512）。
- 无抗锯齿、无渐变、无柔光、无阴影，硬像素边缘。
- 四色平涂：深棕 `#4B3527`（轮廓 / 五官）、奶油橘 `#F6D5A0`（猫）、
  暖白 `#FFF6E2`（云）、浅蓝灰 `#B9C9D8`（云底）。
- 同组帧画布、比例、身体基准点一致；只有尾巴和眼睛在变。
- 每帧四周至少留 1 逻辑像素透明余量（`bottom-*` 例外：爪子按需求搭在下边缘）。
- 素材内没有手机边框、界面线、文字、按钮或对话气泡。

## 尾巴循环

`01 → 02 → 03 → 04 → 03 → 02`，第 01 帧为尾巴中位。半眯眼与闭眼帧的身体和尾巴
对齐 `01`，代码里直接替换即可，不会跳位。

## 播放建议

| 动画 | 帧序 | 建议时长 |
|---|---|---|
| 待机 | 01→02→03→04→03→02 | 每帧 180–220ms |
| 眨眼 | half → closed → half → 01 | half 120ms、closed 100ms |
| 拖动 | 01→02→03→04 | 每帧 200ms，整体跟手位移由代码做 |
| 起跳 | jump-01 → 02 → 03 → 04 | 每帧 90–120ms，然后接 `chat-cloud-idle-01` |
| 收起 | 反向复用 jump-04 → 03 → 02 → 01 | 同上 |

## 接入备注

- 各帧画布 64×64，锚点统一取画布中心即可；同组不要逐帧自动裁切或重新居中，否则会抖。
- `icon-cloud-cat.png` 是 512×512，Android 启动器遮罩和底色由接入时处理。
- 上边不设停靠点；移动路径、吸附回弹、云淡入淡出全部由代码控制。
